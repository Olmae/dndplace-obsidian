# Восстановление и диагностика

- При неизвестном результате отправки нажмите **На сайт → Продолжить отправку**. Не создавайте новую отправку: сохранённые идентификаторы позволяют найти результат старой без повторного применения.
- При конфликте откройте сравнение. Можно взять текст сайта, сохранить локальный поверх проверенной версии сайта, создать отдельную локальную копию или отложить решение. Перезапись сайта требует отдельного финального подтверждения.
- История содержит версии сайта и локальные копии. **Восстановить текст локально** меняет только текст выбранного файла; изображения и холст не восстанавливаются и ничего не отправляется. Старая версия остаётся в локальной истории.
- Для восстановления на сайте перейдите по ссылке записи и нажмите **История изменений**. Авторизация выполняется в браузере, не через ключ плагина.
- **Пауза** сохраняет файлы, привязку, очередь и резервные копии. Не переносите служебную очередь в другую папку или кампанию. После возобновления продолжите незавершённый обмен вручную.
- При отзыве ключа заново проверьте разрешения на сайте. Автообмен останавливается при отказе доступа и конфликтах; после устранения причины выключите и снова включите его.

Журналы в `.obsidian/plugins/dndplace-sync/sync-state-v1` содержат приватный текст. Не удаляйте их при незавершённых операциях. Для обращения за помощью достаточно версии Obsidian/плагина, названия действия и текста ошибки; не присылайте ключи и приватные заметки.
