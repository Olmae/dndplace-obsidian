# DNDPlace Sync 0.1.0 · тестовый релиз

Устанавливается вручную или через BRAT по репозиторию `Olmae/dndplace-obsidian`. Это предварительная версия для совместного тестирования, не выпуск в официальном каталоге Obsidian.

В релизе: несколько сайтов и кампаний, отдельные папки, ручной обмен Markdown и изображениями, проверка перед записью, восстановление незавершённых отправок, история, локальное восстановление текста и четыре решения конфликтов. Автообмен включается отдельно после успешного ручного переноса и работает только с уже связанными записями. Новые записи, несохранённые правки и конфликты требуют участия пользователя.

Добавлены строгие блоки `dndplace-check`, команда вставки проверки, локальный пробный бросок и оформление callout-блоков. Пробные броски не создают событий на сайте и не учитывают бонусы листа персонажа.

Начните с отдельной папки и тестовой кампании. Инструкция: [installation.md](installation.md). Восстановление: [recovery.md](recovery.md). Границы редактора: [editor-compatibility.md](editor-compatibility.md).

Проверено на macOS в отдельном Obsidian 1.14.4: загрузка, защищённое хранилище, подключение через интерфейс, привязка папки, выбор файла, подготовка пакета, подтверждение сайта, получение результата и повторная загрузка плагина с сохранением идентификатора устройства. Дополнительно выполняются автоматические проверки и обмен через изолированные HTTP/SQLite-стенды.

Ещё не подтверждены: Windows/Linux, два физических устройства, другие синхронизаторы и реальные сбои питания. Полный Word-подобный интерфейс сайта в Obsidian не переносится. Пользовательскую лицензию проекта пока не выбирали; сторонние библиотеки перечислены в `THIRD-PARTY-NOTICES.txt`.
