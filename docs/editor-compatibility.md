# Совместимость редактора · 0.1.0

| Возможность | Поддержка |
| --- | --- |
| Обычный Markdown, заголовки, списки, таблицы, ссылки | Нативный редактор Obsidian |
| YAML, BOM и CRLF | Сохраняются при переносе; неизвестные свойства не выполняются |
| `[[вики-ссылки]]`, изображения внутри папки кампании | Переносятся с проверкой путей и содержимого |
| `dndplace-check` | Отображение в режиме чтения, строгие JSON/YAML, СЛ 1–40, преимущество/помеха |
| Команда «Добавить проверку» | Выбор канонического навыка/характеристики/спасброска и вставка блока |
| Пробный бросок | Только локальное отображение, без бонусов листа и без событий кампании |
| `read-aloud`, `gm-secret`, `note`, `danger` | Нативные callout-блоки с оформлением; секретный блок не скрывает файл от владельца хранилища |
| Холст записи сайта | Сохраняется как отдельное служебное состояние; визуального редактора холста в плагине нет |
| Произвольный HTML, Dataview и сторонние плагины | Плагин не выполняет их; неизвестные конструкции сохраняются как исходный текст |
| Полный Word-подобный интерфейс сайта | Не заявлен; панели и возможности редакторов отличаются |

Проверено на macOS в отдельном Obsidian 1.14.4. Windows, Linux, мобильные устройства и одновременная работа с другими синхронизаторами требуют отдельной проверки. Синтетические HTTP/SQLite-тесты не заменяют испытание на двух физических устройствах.
