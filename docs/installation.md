# Установка тестового релиза 0.1.0

Нужен Obsidian Desktop 1.11.4 или новее. Для первого запуска используйте отдельное хранилище и тестовую кампанию.

1. Закройте Obsidian. Распакуйте папку `dndplace-sync` из ZIP в `<хранилище>/.obsidian/plugins/`.
2. Откройте Obsidian, разрешите сторонние плагины и включите **DNDPlace Sync**.
3. На DNDPlace откройте `/profile/integrations/obsidian`. Создайте отдельный ключ, выберите кампанию и разрешения чтения, записи и истории. Ключ показывается один раз.
4. Нажмите значок d20 в Obsidian. Добавьте адрес сайта и ключ. Выберите кампанию, привязку архива и существующую отдельную папку внутри хранилища.
5. Выполните первый обмен вручную: выберите записи, просмотрите изменения и подтвердите. Отправка требует двух подтверждений: состав пакета и план сайта.
6. При желании включите автообмен в настройках плагина для этой папки. Сначала должен завершиться ручной обмен без конфликтов и незавершённых операций.

Автообмен работает только с уже связанными записями: новые записи сначала отправьте или получите вручную. Изменения проверяются через 1,5 секунды после локального события и каждые 30 секунд. Конфликты, удаление, перемещение и несохранённый текст требуют ручной проверки.

Ключ хранится в SecretStorage Obsidian, а не в `data.json`. Не размещайте локальные журналы и резервные копии в публичном репозитории. Публичный адрес требует HTTPS; HTTP разрешён только для локального loopback.

Это тестовый релиз, не публикация в каталоге Obsidian. Не включайте одновременно другой двусторонний синхронизатор для тех же файлов без собственной резервной копии.
